# todo-react

[English](README.md) · Norsk

Todo-app med React 19 og Vite. Legg til, endre, slett, søk og filtrer oppgaver. Laget for å øve på Feature-Sliced Design.

I dev bruker den et falskt REST-API (`json-server` + `db.json5`), i produksjon lagres oppgavene i localStorage. Routeren er skrevet for hånd, uten bibliotek.

## Kjør

```bash
npm install
npm run dev
npm run server
```
