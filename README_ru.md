# Todo React Application

Современное todo-приложение, построенное на React 19, Vite и архитектуре Feature-Sliced Design.

## 🎨 О Проекте

Todo React — это полнофункциональное приложение для управления задачами с чистой архитектурой, кастомной маршрутизацией и двумя режимами хранения данных (LocalStorage и REST API). Демонстрирует современные паттерны React-разработки и Feature-Sliced Design методологию.

## ✨ Возможности

- ✅ Создание, чтение, обновление и удаление задач
- 🔍 Поиск и фильтрация в реальном времени
- 📊 Статистика задач (выполнено/всего)
- 🎯 Автопрокрутка к первой невыполненной задаче
- ✨ Плавные анимации операций с задачами
- 💾 Персистентность LocalStorage (продакшен)
- 🔌 Демо интеграции REST API (разработка)
- 🎨 Кастомная маршрутизация без внешних библиотек
- 📱 Адаптивный дизайн

## 🛠️ Технологии

- **React 19.1.0** — UI библиотека
- **Vite 7.0.4** — Инструмент сборки и dev-сервер
- **SCSS Modules** — Стилизация компонентов
- **JSON Server** — Mock REST API для разработки
- **Custom Router** — Клиентская маршрутизация через History API

## 💾 Управление Данными

Приложение поддерживает два режима хранения данных:

### 1. LocalStorage (Продакшен)
- Режим по умолчанию для развернутого приложения
- Данные сохраняются в браузерном хранилище
- Не требует бэкенда
- Симулирует асинхронные операции с задержками

### 2. JSON Server (Демо Разработки)
- Демонстрирует интеграцию REST API
- Полные CRUD операции через fetch
- Запускается на `http://localhost:3001`

Переключение между режимами в `src/shared/api/tasks/index.js`:
```javascript
const USE_LOCAL_STORAGE = true // false для JSON Server
```

## 🎯 Ключевые Особенности

### Кастомный Роутер
Легковесная реализация маршрутизации через History API без внешних зависимостей:
- Динамическое сопоставление маршрутов с параметрами (`/tasks/:id`)
- Программная навигация
- Поддержка браузерной навигации назад/вперед

### Управление Состоянием
Context API с кастомными хуками:
- `TasksProvider` — Глобальный контейнер состояния
- `useTasks` — Операции и состояние задач
- `useIncompleteTaskScroll` — Функциональность автопрокрутки

### API Слой
Абстракция над источниками данных:
- Единый интерфейс для LocalStorage и Server API
- Легкое переключение между реализациями
- Паттерн async/await повсюду

### Анимации
CSS-анимации для:
- Появления задачи при создании
- Исчезновения задачи при удалении
- Плавной переупорядочивания списка

### Валидация Форм
Валидация в реальном времени с сообщениями об ошибках:
- Предотвращение пустых задач
- Определение ввода только пробелов
- Визуальная обратная связь
